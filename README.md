# Notfall-Tresor – Downloads

Hier stehen die veröffentlichten Fassungen des Notfall-Tresors: die Programmdatei `notfall-tresor.html` und ihre Prüfsumme `SHA256SUMS`.

Die neueste Fassung steht rechts unter «Releases».

Prüfsumme kontrollieren: unter Windows `certutil -hashfile notfall-tresor.html SHA256`, unter macOS `shasum -a 256 notfall-tresor.html`. Der Wert muss mit dem Release übereinstimmen.
